# 版本更新日志

## 插件版 v1.0.0 [2026-08-12]

- 项目统一命名为 **99AI Plugin Edition（99AI-插件版）**。
- 首次管理员改为部署者显式注入强密码；缺少安全密码时服务拒绝初始化。
- 强化验证码、会话撤销、游客额度、接口限流、TTS 记录归属和 MCP 工具权限。
- 微信扫码登录、绑定与旧账号迁移增加浏览器/微信配对码核对及扫码者二次确认；旧账号标识迁移改为数据库事务。
- 清理认证、公众号、上传和支付相关日志中的敏感内容。
- 使用 ExcelJS 替换旧表格解析依赖，内置表格预览以 `.xlsx` 为主。
- 增加 Apache-2.0 官方许可证、第三方归属说明和全新仓库导出流程。
